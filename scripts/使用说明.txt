snap —— 安装与使用（先看这三步）
==================================================

1) 把这个文件夹放到 C 盘
   建议直接解压到 C:\snap。路径尽量别带空格和中文，最省事。
   文件夹里应该有这些文件：

       snap.exe          主程序（单文件、无运行时依赖）
       add-to-path.bat   把本文件夹加入 PATH —— 双击运行它
       add-to-path.ps1   上面那个脚本的逻辑，不用手动打开
       README.md         完整说明（命令表、安全机制、性能）
       CHANGELOG.md      版本变更记录
       LICENSE           MIT 许可证

2) 双击 add-to-path.bat
   它会把 C:\snap 加入「当前用户」的 PATH，不需要管理员权限。
   改之前会自动把原来的 PATH 备份到 %TEMP% 目录，随时可回退。

       先看看会改什么（不真改）：add-to-path.bat /dry-run
       改系统级 PATH（所有用户，要管理员）：右键以管理员身份运行，加 /machine
       从 PATH 移除：add-to-path.bat /remove

3) 重新开一个终端窗口，就可以到处直接用了

       snap -i              在当前目录初始化
       snap -t              看改了什么（+ 新增 / M 修改 / - 删除）
       snap -s "说明"        存一个版本
       snap -l              看历史
       snap -c <版本号>      切回某个版本（写前几位前缀即可）
       snap -h              看全部命令

--------------------------------------------------
备注
--------------------------------------------------
· 不想装 PATH 也能用：在项目目录里执行 C:\snap\snap.exe -t 即可。
· 如果提示「不是内部或外部命令」，是第 3 步的窗口没重开（PATH 只对新开的窗口生效）。
· 安装脚本用 PowerShell 实现。若系统提示脚本被禁止运行，可以在命令行里执行：
      powershell -NoProfile -ExecutionPolicy Bypass -File add-to-path.ps1 -DryRun
· 更详细的说明、性能数据与设计取舍见 README.md。
